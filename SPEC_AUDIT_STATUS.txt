PART 2 — SPEED / QUALITY / FRESHNESS ARCHITECTURE
================================================================================
Overall: IMPLEMENTED AND LIVE-VERIFIED. Root cause was a monolithic scan
loop that deep-analyzed the full 241-symbol universe across all 7 timeframes
every cycle, with zero candle caching. Rebuilt as a two-stage scan (cheap
full-universe Stage-1 filter -> deep Stage-2 only on a shortlist) + a TTL
candle cache + a dedicated ~1-minute Critical-trade monitor decoupled from
the general scan. Measured live on the real server (D:\Groww,
src/candle_cache.mjs, src/stage1_filter.mjs, src/session_candles.mjs,
src/critical_monitor.mjs, scanner.mjs restructured):
  Cycle 1 (cold cache):  449s  (~7.5 min) — 1,320 candle fetches, 0 cache hits
  Cycle 2 (warm cache):  168s  (~2.8 min) — 269 cache hits of ~560 requests
That's a 2.7x cycle-over-cycle speedup, landing well inside the ~5-minute
general-refresh target (vs. the original ~20-25 min baseline — roughly an
8-9x improvement in steady state).
